# bcgwcat2: BC Groundwater Chemistry Analysis Tool

Set of tools for working with groundwater chemstry data from the BC
Government EnMoDS (Environmental Monitoring Data System). Download
EnMoDS data and a) export, b) view water quality summaries, c) create
piper and stiff plots.
